Un archivo por pregunta (p. ej. `modelo-datos.md`, `seguridad.md`, `contratos-api.md`,
`despliegue.md`). Antes de escribir una frase aquí, pásale la
[prueba de la frontera](../README.md#la-prueba-de-la-frontera): si producto podría cambiarla sin que
la arquitectura se mueva, no es arquitectura, es un criterio de aceptación.
